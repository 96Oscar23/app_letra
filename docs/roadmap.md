# Roadmap

Roadmap del proyecto.

## Objetivo

Aquí se describirán las fases y el alcance de cada etapa del desarrollo.  
Aún no está todo completamente definido, ya que varios elementos se irán aterrizando sobre la marcha. Sin embargo, el propósito general del proyecto se mantiene:

Pasar de tener las letras en Google Drive a contar con una aplicación propia donde se puedan registrar, consultar y administrar fácilmente. Esto nace de la necesidad de evitar la pérdida de letras, mejorar la búsqueda de cantos y tener un mayor control sobre las canciones, sus tonos, repertorios y la experiencia de uso en vivo.
