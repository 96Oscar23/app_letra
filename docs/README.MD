# Documentación del proyecto

Este directorio contiene la documentación principal del proyecto, incluyendo visión general, roadmap, decisiones tomadas, modelos base y el detalle de cada fase de desarrollo.

## Estructura de documentación

### Archivos generales

- `roadmap.md`  
  Contiene el roadmap completo del proyecto, dividido por fases y entregables.

- `decisiones.md`  
  Registra decisiones importantes del proyecto, tanto técnicas como funcionales, para dejar claro por qué se eligió cierto enfoque.

- `modelos.md`  
  Describe los modelos principales del sistema, sus relaciones y el propósito de cada entidad.

- `vision.md`  
  Explica la visión general del producto, el problema que busca resolver, el tipo de usuario al que va dirigido y la idea general de evolución.

## Fases

Dentro de la carpeta `fases/` se documenta el detalle de cada fase del roadmap.

Cada archivo de fase puede incluir:

- objetivo de la fase
- alcance
- pantallas involucradas
- flujo funcional
- tareas principales
- dependencias
- entregable esperado

Ejemplo de nombres de archivos:

- `fase-0-diseno-ux.md`
- `fase-1-base-cantos.md`
- `fase-2-alta-rapida-importacion.md`

## Objetivo de esta documentación

Tener una base clara para:

- organizar el desarrollo del proyecto
- documentar decisiones importantes
- facilitar retomar el proyecto después
- mantener claridad sobre el alcance de cada fase
- evitar que ideas importantes se pierdan con el tiempo

## Nota

La documentación irá evolucionando junto con el proyecto.  
No todos los puntos están completamente cerrados desde el inicio, por lo que algunos documentos podrán ajustarse conforme avance el desarrollo.
